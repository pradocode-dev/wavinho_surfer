# wavinho_surfer
Um jogo de surf arcade pixel art com progressão infinita de velocidade, desenvolvido em HTML5 Canvas puro e JavaScript. O jogador controla o Wavinho, desviando de obstáculos como boias e gaivotas, coletando sushis e desbloqueando companheiros especiais (Hiro, Ura e Maki) para combos e defesas épicas.
